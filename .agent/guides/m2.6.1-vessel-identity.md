# M2.6.1 — vessel identity

Status: **implemented.** The editor is in `.agent/guides/m2.6.2-boat-profile.md`. Hull and rig are in `.agent/guides/m2.6.3-hull-rig.md`. Sails are in `.agent/guides/m2.6.4-sail-inventory.md`. Do not start M2.6.5.

Vessels are records in `vessel-profiles.json` under Application Support / MarineSimulator. The file is separate from simulator settings so a physics tick does not rewrite the library. Writes use an atomic file replace. A file that cannot be decoded, or whose schema is not version 1, is left as it is.

Extasy `8F3C1A40-1999-4A07-8E35-4070F1A7E001` carries the existing Farr Design #354 polar. Nimana `6B2D4E46-2015-4B46-9C12-46A0B1C2D003` has no polar. Both ids are constants. Built-in records cannot be renamed or deleted. Duplicating one creates a custom vessel with a new id and no polar.

The active id is stored in simulator settings. No stored selection, including an older settings file that never had a vessel key, selects Extasy. A stored id or legacy name that does not resolve stays unresolved, keeps that reference, and does not select another vessel. Transmission and maneuvers do not start until the user picks a vessel.

Changing vessel while a run is already going is allowed. The next cycle reads one new configuration snapshot. The tick remains the only heading writer. A custom vessel uses no speed polar, so From Wind holds the current boat speed.

The profile editor, sail inventory, and ORC import are not part of this step. Hull and rig landed in M2.6.3.
