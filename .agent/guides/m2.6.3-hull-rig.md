# M2.6.3 — vessel identity, hull, and rig

Status: **implemented.** Sail inventory is in `.agent/guides/m2.6.4-sail-inventory.md`. Do not start M2.6.5.

## Schema

`vessel-profiles.json` current schema is **2**. This build reads schemas **1** and **2**. A valid schema 1 library is rewritten once as schema 2 by the existing validated-save path. Built-in rows are replaced with the current seeds. Custom rows keep their UUID, name, model, year, and any measurements already stored. Missing hull and rig keys decode as unknown, not zero.

Schema 0, schema 99, corrupt JSON, a negative or non-positive stored dimension, and a construction year outside 1800...2100 still throw. Those files are not rewritten.

## Fields

Identity: name (required), builder, model, construction year, sail number, registration. UUID and origin stay as they were.

Hull, metres except displacement: LOA, LWL, maximum beam, draft, displacement in kilograms.

Rig, metres, sail-plan dimensions: I foretriangle height, J foretriangle base, P mainsail luff, E mainsail foot. These are not measurements of a particular sail.

Empty text is unknown. Zero, negative, and non-finite numbers are rejected. Internal storage is metres and kilograms. Nothing fills a blank field.

## Sources

Read from the rendered ORC Club certificate pages. The earlier text extraction of P as 4.710 m and 6.550 m dropped the leading digit of `P14.710` and `P16.550`.

| J, P, E | 4.420 m, 14.710 m, 5.370 m | 5.510 m, 16.550 m, 5.450 m |
| I | printed N/A, stored unknown | printed N/A, stored unknown |
| LWL | not printed, stored unknown | not printed, stored unknown |
| Registration | HIN blank, stored unknown | HIN blank, stored unknown |

IMS L and IG are different printed quantities and are not stored as LWL or I. Certificate numbers are not stored as registration. The PDFs were not modified.

## Editor

Setup → Boat Profile sections are Identity, Hull, Rig, and Sail inventory. Units sit beside the numeric fields. Built-in identity rows stay read-only. Valid custom edits autosave. Invalid or incomplete text stays editable and does not replace the last saved value. A failed write keeps the typed text and the previous library. A blank measurement means unknown. Sail editing is described in `.agent/guides/m2.6.4-sail-inventory.md`. There is no polar or certificate tab.

## Simulation

Hull and rig values are not read by speed, dynamics, polar interpolation, maneuvers, heading, wind, or NMEA. Extasy still uses Farr Design #354. Nimana and custom vessels still have no polar.
