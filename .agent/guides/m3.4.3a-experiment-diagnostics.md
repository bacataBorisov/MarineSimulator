# Experiment Diagnostics

Status: **an isolated engineering page.** It prepares and steps one experiment. It does not replace the operator simulator, and opening it does not start a run.

## Open the page

Choose **Diagnostics** in the Setup section of the sidebar. The window starts inactive. The operator dashboard, sentence pages, and transmit loop are unchanged.

## Prepare and run

**Prepare** copies a clean baseline and calls `ExperimentScenarioRunner.prepare`. The baseline is a fixed position, heading, and estimated-speed setup in a private defaults suite. It is not the live operator session.

**Start** steps the existing `SimulationEngine` by 0.05 s and then continues in real time while the page is visible. **Pause** stops that loop. **Resume** continues the same runtime and the same measurement generator. **Reset** prepares again, so the random sequence starts at the first sample.

The run stops at the last whole 0.05 s step that fits in the duration. Leaving the page pauses the loop. The operator Start button is a different loop and does not advance this runtime.

## What applies when

Seed, wind direction, wind speed, duration, bias, and noise are stored in memory. They are copied onto the runtime by Prepare and Reset. Edits during a run do not change the sample already in progress. The page says so when a prepared run is behind the edited fields.

Noise amplitude must be zero or positive. A negative or unreadable value is rejected and the previous value stays. Nothing in this page is written to `UserDefaults`.

## Truth and measurements

Physical truth is `EnvironmentTruth` and `VesselTruth` after the engine step. Ideal apparent wind is `ExperimentSensorModel.apparentWind` from that truth. Instrument rows are the stored publication. A missing sample is shown as Unavailable, including before the first step. Zero is shown only when the value is actually zero.

The page does not name the hidden polar. The diagnostics scenario uses the Extasy table for both the reference and the hidden profile, so this page cannot select a different hidden identity.

## Sensor switches

The four toggles are the experiment anemometer, speed log, gyro, and compass. They are written into that runtime’s `SensorToggleStates` on the next step. They do not change vessel truth. A disabled instrument leaves its measurement Unavailable. The page does not copy physical truth into the gap.

## NMEA

The NMEA section prints MWV relative, MWV true, MWD, VHW, HDG, and HDT from the stored snapshot, using the existing builders and checksums. Building those lines does not draw a new measurement. An unavailable input is omitted by the builder and the row says Unavailable.

## Reproducibility

The same seed, wind, duration, errors, switches, and step count repeat the readout. The simulation clock starts at a fixed instant, not the wall clock. The 1 Hz environment redraw still runs after one second of simulation time and uses the experiment’s physical random stream. Wire faults are not applied on this page.

## Limits

There is no chart, no scenario file, and no error preset. The true-heading row is the direct heading instrument, not a gyrocompass. ROT is not shown. GNSS, depth, heel, delay, and dropout are not measured. Estimated speed can move speed through water away from the baseline as soon as the run starts, because that motion belongs to the physical model.
