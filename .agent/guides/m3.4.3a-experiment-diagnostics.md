# Experiment Diagnostics

Status: **an isolated engineering and dataset-generation page.** It prepares, steps, and exports one controlled experiment. It does not replace the operator simulator, and opening it does not start a run.

## Open the page

Choose **Diagnostics** in the Setup section of the sidebar. The window starts inactive. The operator dashboard, sentence pages, and transmit loop are unchanged.

## Prepare, run, and export

**Prepare** copies a clean baseline and calls `ExperimentScenarioRunner.prepare`. The baseline is a fixed position, heading, and estimated-speed setup in a private defaults suite. It is not the live operator session.

**Start** steps the existing `SimulationEngine` by `0.05 s` and continues in real time while the page is visible. **Pause** stops that loop. **Resume** continues the same runtime and the same measurement generator. **Reset** prepares again, clearing recorded CSV samples and restarting the random sequence at sample 0.

The run stops at the last whole `0.05 s` step that fits in the duration. Leaving the page pauses the loop. The operator Start button is a different loop and does not advance this runtime.

**Export CSV…** and **Export Truth…** write the buffered `sampleIntervalSeconds` (`1 s`) rows via `NSSavePanel` (`Model/ExperimentDatasetExporter.swift`):
- `Export CSV…` obeys `ExperimentOutputContract` (`timestamp,trueWindDirection,trueWindSpeed,trueHeading,speedThroughWater` by default, `permitsGroundTruthExport = false`), excluding ground truth and hidden polar factors.
- `Export Truth…` writes physical ground truth separately for offline evaluation/RMSE scoring.

## What applies when and persistence

All scenario controls (`Seed`, `Wind direction`, `Wind speed`, `Wind dir swing`, `Wind speed amp`, `Wind cycle period`, `Boat heading`, `Course sweep`, `Current set`, `Current drift`, `Duration`), `Hidden Polar Factors` (`Speed response`, `Hull factor`, `Sail factor`, `Trim efficiency`, `Sea state factor`), `Sensor Availability`, and `Error Configuration` (`Bias`, `Noise`) are copied onto the runtime on **Prepare** and **Reset** (clicking any action button first resigns focus to commit the active field). Edits during a run do not mutate the run in progress; a pending-changes notice indicates when **Prepare** or **Reset** is needed.

In the app (`MainView`), `ExperimentDiagnosticsSession` persists entered inputs under `UserDefaults.standard` key `"experiment_diagnostics.inputs"` across restarts, while test instances default to `userDefaults: nil` for isolation. Operator simulator settings are never read or written.

## Truth and measurements

Physical truth is `EnvironmentTruth` and `VesselTruth` after the engine step, including `Current set`/`drift`, `Speed through water` (shown with `% of reference`), and `Reference polar STW` (First 40.7 lookup at current truth TWS/TWA). Ideal apparent wind is `ExperimentSensorModel.apparentWind` from that truth. Instrument rows are the stored publication. A missing sample is shown as `Unavailable`, including before the first step; zero is shown only when the value is actually zero.

## Sensor switches

The four toggles are the experiment anemometer, speed log, gyro, and compass. They are written into that runtime’s `SensorToggleStates` on the next step. They do not change vessel truth. A disabled instrument leaves its measurement `Unavailable`.

## NMEA

The NMEA section prints `MWV` relative, `MWV` true, `MWD`, `VHW`, `HDG`, and `HDT` on single lines from the stored snapshot, using the existing builders and checksums. Building those lines does not draw a new measurement. An unavailable input is omitted by the builder and the row says `Unavailable`.

## Reproducibility

The same seed, scenario controls, hidden factors, errors, switches, and step count repeat the readout and exported CSV byte-for-byte. The simulation clock starts at a fixed instant (`2027-01-15T08:00:00Z`), not the wall clock. Wire faults are not applied on this page.

## Limits

There is no chart, no saved JSON scenario library UI, and no in-app polar comparison chart/table (`PolarResearchStudio` is planned for M4). The true-heading row is the direct heading instrument, not a gyrocompass. GNSS, depth, heel, delay, drift, and dropout are not measured.
