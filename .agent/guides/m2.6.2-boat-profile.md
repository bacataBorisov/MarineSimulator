# M2.6.2 — boat profile management

Status: **implemented.** Hull and rig are in `.agent/guides/m2.6.3-hull-rig.md`. Sails are in `.agent/guides/m2.6.4-sail-inventory.md`. Do not start M2.6.5.

Setup → Boat Profile is a library list and a detail form. The list highlight is the vessel being inspected. The active vessel is still `SimulatorSettings.activeVesselID`, changed only by Set as Active Vessel or the dashboard picker. Both read the same simulator selection.

New, Duplicate, Rename, and Delete call `VesselLibrarySession`, which calls the existing repository. A failed write leaves the library as it was and shows the repository error. Built-in rows are read-only. A new or duplicated vessel gets a new UUID, no polar, and the name “<original> Copy” when duplicated. Deleting the active custom vessel leaves that UUID unresolved and stops transmission.

The detail shows identity, hull, rig, sail inventory, the stored sail selection, UUID, origin, and performance. UUID is not editable. Valid edits to a custom vessel, including hull, rig, and sails, save immediately. Invalid text stays in the field and does not replace the last saved profile. Built-in identity stays read-only. Sails on a built-in vessel can be saved without changing that identity. Switching profiles does not ask to save or discard. A failed write blocks the switch and shows the error. Highlighting still does not change the active vessel. Polars and certificates are not on this screen.

Maneuvers and the heading setpoint stay on Dashboard → Boat.
