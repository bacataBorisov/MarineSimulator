# M2.5.2 and M2.6 — boat profile and maneuvers

Status: **M2.6.1 stores vessels by UUID.** Extasy and Nimana are the seeded profiles. A stored reference that cannot be resolved stays unresolved. Do not start M2.6.2 or Milestone 3.

## Decisions

The Setup sidebar item **Boat** becomes **Boat Profile**. It stays under Setup. There is no second manager in Settings. The stored sidebar value stays `boat`, so a saved selection still opens that page.

Boat Profile holds persistent vessel data only. Each vessel has its own UUID, so two boats of the same model can both exist. The simulator reads the active profile and does not write heading, wind, speed, sailing state, or the active maneuver back into it. Persistent edits are explicit saves. Duplicate, import, and restore must not overwrite an existing profile or an imported dataset. Provenance and certificate references stay with the dataset.

Maneuver duration and speed retention stay simulator settings. They are not part of the static profile.

## Where the controls go

The Dashboard is a map with a 352 pt left rail and a right inspector. The rail has one segmented control: Wind, Env, Hydro, Heading, Boat. The simulation tick is the only heading writer.

Dashboard → Boat holds the vessel picker, Manual / From Wind, the heading setpoint, the four tack and gybe buttons, and a collapsed compass-measurement disclosure. See `.agent/guides/m2.5-controls.md`. The Heading segment stays as a readout and does not write heading. The tick remains the only heading writer.

The Setup Boat Profile page is the vessel library. Maneuvers and speed mode stay on the Dashboard Boat segment. See `.agent/guides/m2.6.2-boat-profile.md`.
